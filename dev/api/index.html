EasyDraw.EasyDraw — Module
EasyDraw

Draw the zones of a 2D (x–z) model in a window, or write them in code, and get them back as data for a solver: the zone or a property at any coordinates, for finite differences and particles, or disjoint regions written as a Gmsh script, for finite elements.

  • Shapes and zones: Polygon, Block, Ball, Region, Zone; a point belongs to the last zone that contains it.
  • The model: Layout, save_layout, load_layout.
  • The window: draw, offering what its host's Catalog lists.
  • On a grid: zone_at, zone_index, property, points.
  • For a mesher: partition, write_geo.

Shapes

EasyDraw.AbstractShape — Type
AbstractShape

The supertype of a zone's shape: Polygon, Block, Ball or Region. inside(shape, x) tells whether a point lies in it.

A new shape is a subtype with an inside method. Like a Region, it then works in code (sampling, points) but cannot be written to a file, drawn in the window or partitioned.

source
EasyDraw.Polygon — Type
Polygon

A polygon in the x–z plane, of one outline or several. In 3D it is extruded along y.

A point is inside when it lies inside an odd number of the outlines (the even–odd rule), so several outlines make one zone of several parts, or with holes. The window leaves a zone in this form when a later zone cuts it.

Fields

  • vertices::Vector{Vector{Float64}}: the [x, z] vertices of every outline, one outline after the other, the first vertex of each not repeated at its end.
  • sizes::Vector{Int}: how many vertices each outline has.

Constructors

Polygon(vertices)          # one outline: a vector of [x, z] vertices
Polygon(rings)             # several outlines: a vector of such vectors
Polygon(vertices, sizes)   # the fields themselves

Throws

  • ArgumentError: when an outline has fewer than 3 vertices, a vertex is not two coordinates, or sizes does not add up to the number of vertices.

Examples

julia> square = Polygon([[0, 0], [4, 0], [4, 4], [0, 4]]);

julia> inside(square, (1.0, 1.0))
true

julia> frame = Polygon([[[0, 0], [4, 0], [4, 4], [0, 4]], [[1, 1], [3, 1], [3, 3], [1, 3]]]);   # with a hole

julia> inside(frame, (2.0, 2.0)), frame.sizes
(false, [4, 4])

See also polygon_rings, inside.

EasyDraw.Block — Type
Block

The axis-aligned box lo ≤ x ≤ hi, its bounds included. Given by two coordinates (x, z), it is extruded along y in 3D.

Fields

  • lo::Vector{Float64}: the lower corner.
  • hi::Vector{Float64}: the upper corner.

Constructors

Block(lo, hi)

Throws

  • ArgumentError: when lo and hi differ in length, or lo exceeds hi along an axis.

Examples

julia> b = Block([0, 0], [10, 2]);

julia> inside(b, (10.0, 2.0)), inside(b, (5.0, 3.0))
(true, false)

EasyDraw.Ball — Type
Ball

The points at most radius from centre: a disk in 2D, a sphere in 3D, or, with a two-coordinate (x, z) centre in 3D, a cylinder along y. The circle itself is included.

Fields

Throws

EasyDraw.Region — Type
Region{F}

The points x for which f(x) is true: any shape, written as a Julia function. x holds the point's coordinates, (x, z) in 2D, so x[end] is its height in 2D and 3D alike.

A Region works in code only: it cannot be written to a file, drawn in the window or partitioned.

Fields

  • f::F: the predicate, returning a Bool.

Constructors

Region(f)

Examples

julia> above = Region(x -> x[end] > 0.5x[1]);   # above the line z = x/2

julia> inside(above, (2.0, 3.0))
true

EasyDraw.inside — Function
inside(shape::AbstractShape, x) -> Bool

Whether the point x (its coordinates, (x, z) or (x, y, z)) lies in shape:

  • a Polygon by the even–odd rule over all its outlines;
  • a Block with its bounds included;
  • a Ball as its closed disk or sphere;
  • a Region by its predicate.

A shape given by two coordinates reads a 3D point's x and z, so it is extruded along y.

Throws

  • ArgumentError: when a Block or Ball has neither as many coordinates as the point nor two.

Examples

julia> inside(Ball([0, 0], 1.0), (0.5, 0.5))
true

julia> inside(Block([0, 0], [1, 1]), (0.5, 7.0, 0.5))   # an (x, z) block in 3D: extruded along y
true

EasyDraw.inpolygon — Function
inpolygon(x, z, vertices) -> Bool

Whether the point (x, z) lies inside the polygon with these vertices ([x, z] pairs, the first not repeated at the end), by the even–odd rule, so that concave and self-touching polygons work. A point exactly on an edge may count as either side.

Examples

julia> inpolygon(1.0, 1.0, [[0, 0], [4, 0], [4, 4], [0, 4]])
true

See also inside, Polygon.

Zones and layouts

EasyDraw.Zone — Type
Zone

A named part of a model: the points in its shape, with properties of any name. Where zones overlap, a point belongs to the last zone that contains it.

Fields

  • name::String: the zone's name.
  • shape::AbstractShape: its Polygon, Block, Ball or Region.
  • props::Dict{Symbol,Any}: its properties. A number is stored as a Float64, a list of numbers as a Vector{Float64}, anything else as given.

Constructors

Zone(name, shape; props...)
Zone(name, shape, props::AbstractDict)

Examples

julia> z = Zone("lens", Ball([5, 2], 1.0); rho=2100, note="wet");

julia> z.props[:rho], z.props[:note]
(2100.0, "wet")

See also Layout, zone_at.

EasyDraw.Layout — Type
Layout

A 2D (x–z) model, as drawn in the window or written in code: its domain, its zones, a boundary kind per side, and the values its host's Catalog asks for. Values are kept as given: SI in, SI out.

Fields

  • L::Vector{Float64}: the domain's size [Lx, Lz]: the domain is [0, Lx] × [0, Lz].
  • nel::Vector{Int}: the number of cells along x and z.
  • ni::Int: points per cell and axis, where the window previews points and points samples (1: the cell centres).
  • width::Union{Nothing,Float64}: a width along y, to extrude the model in 3D; nothing in 2D.
  • nely::Union{Nothing,Int}: the number of cells along y, with width.
  • zones::Vector{Zone}: the zones, in order: where they overlap, the later one wins.
  • sides::Dict{String,String}: a boundary kind per side, by "left", "right", "bottom" or "top".
  • defaults::Dict{String,Any}: each zone property's default, by key, for the zones that do not set it.
  • options::Dict{String,Any}: the options set, nested by the parts of their keys: "solver.method" is options["solver"]["method"]. Only the options ticked in the window are there.
  • run::Dict{String,Any}: the run settings, by key.
  • folder::String: the folder the layout was created in (the window's Create…) or read from; "" otherwise.

Constructors

Layout(; L, nel, ni=2, width=nothing, nely=nothing, zones=[], sides=Dict(), defaults=Dict(), options=Dict(),
         run=Dict(), folder="")

Throws

  • ArgumentError: when L or nel does not have 2 entries, a size or count is not positive, only one of width and nely is given, or a side is not one of the four.

Examples

julia> l = Layout(; L=[100, 50], nel=[50, 25], zones=[Zone("lens", Ball([50, 20], 5.0); rho=2100)]);

julia> l.L, l.nel, l.ni
([100.0, 50.0], [50, 25], 2)

See also save_layout, draw.

source
EasyDraw.save_layout — Function
save_layout(file, layout::Layout) -> file

Write layout to file as TOML, making its folder if needed:

  • [domain]: L, nel, ni, and width and nely when the layout is extruded;
  • [sides], [defaults], [run], and [options] as nested tables;
  • one [[zone]] table per zone: its name, its shape (shape = "polygon" with vertices, or rings for several outlines; "block" with lo and hi; "ball" with centre and radius) and its properties.

The folder is not written: it is where the file is.

Throws

  • ArgumentError: when a zone is a Region, a Julia function, which a file cannot hold.

Examples

julia> l = Layout(; L=[10, 5], nel=[10, 5], zones=[Zone("base", Block([0, 0], [10, 2]); rho=2000)]);

julia> file = save_layout(joinpath(mktempdir(), "model_layout.toml"), l);

julia> load_layout(file).zones[1].props[:rho]
2000.0

See also load_layout.

source
EasyDraw.load_layout — Function
load_layout(file) -> Layout

Read a layout from its TOML file, in the format save_layout writes. Its folder is the file's folder.

Tables a layout does not have, from another program's file (an ElastoPlasm case file, say), are ignored with a warning. A zone without a name is called "zone i", by its position.

Throws

  • ArgumentError: when the file has no [domain] table, or a zone's shape is not "polygon", "block" or "ball".

See also draw, which also takes a layout file.

The window

EasyDraw.draw — Function
draw(layout::Layout; catalog=Catalog(), step=2, check, save, load, title="EasyDraw", shots=nothing, startdir=pwd())
draw(file; kwargs...)
draw(; L=[10, 5], nel=[20, 10], ni=2, kwargs...)

Open the drawing window on a layout, a layout file, or a new domain, and wait until it closes. Returns the Layout when Create… wrote it, nothing after Cancel or when the window is closed.

The window has four steps, Domain, Zones, Options (only when the catalog has options) and Run; see Drawing in the window. The first window of a session takes about 20 s, while Qt loads; the next ones open at once.

Arguments

  • catalog: what the window offers: a Catalog, a Dict shaped like its TOML, or a catalog file.
  • step: the step it opens on, 1 (Domain) to 4 (Run): 2 with a layout or a file, 1 for a new domain.
  • check: check(layout) returns (; errors, warnings, info), vectors of strings shown on the Run step: an error blocks Create…, a warning needs a second click. By default: the number of points, and the zones that reach outside the domain or hold no point.
  • save: save(layout, folder) writes the layout into the folder chosen at Create…; by default as <folder name>_layout.toml (save_layout).
  • load: load(file) returns the Layout that "Start from a file…" opens; by default load_layout.
  • title: the window's title.
  • shots: (dir, steps): instead of waiting, save a picture of each listed step into dir (step1.png, …) and close. For tests and documentation, offscreen (QT_QPA_PLATFORM=offscreen).
  • startdir: the folder the file and folder dialogs start in.

Throws

  • ArgumentError: when a zone is a Region or a 3D shape, which the window cannot draw.

Examples

l = draw()                                                      # a new domain
l = draw("model_layout.toml"; catalog="catalog.toml")           # edit a layout, with a host's catalog

Catalogs

EasyDraw.Catalog — Type
Catalog

What the drawing window offers, given by its host program: the properties a zone may set, the boundary kinds, the options and the run settings. An empty catalog gives zones without properties, sides without a kind, and no Options step.

Fields

  • zone::Vector{Field}: the properties a zone may set.
  • boundary::Vector{String}: the kinds of boundary a side may be.
  • colors::Vector{String}: the colour each kind is drawn in ("#4682b4"), or none.
  • side::String: the default kind, the first one unless given.
  • options::Vector{Field}: the options, shown on pages by the first part of their keys.
  • run::Vector{Field}: the run settings.

Constructors

Catalog(; zone=[], boundary=[], colors=[], side="", options=[], run=[])
Catalog(dict)   # plain data shaped like the catalog's TOML (write_catalog), so a host builds no EasyDraw type
Catalog(file)   # that TOML file, as read_catalog

Throws

  • ArgumentError: when there are colours but not one per kind, or side is not one of the kinds.

Examples

julia> c = Catalog(Dict("boundary" => Dict("kinds" => ["free slip", "no slip"]),
                        "zone"     => [Dict("key" => "rho", "label" => "ρ [kg/m³]", "default" => 3300.0)]));

julia> c.side, [f.key for f in c.zone]
("free slip", ["rho"])

See also write_catalog, draw.

source
EasyDraw.Field — Type
Field

One entry of a Catalog: a zone property, an option or a run setting, as the window shows it.

Fields

  • key::String: the key the value is stored under. An option's key starts with its section, the page it is shown on: "solver.method".
  • kind::Symbol: :menu (one of values), :numeric (any number, or a list of numbers when the default is one; values are presets), :integer (a whole number) or :list (several of values).
  • label::String: what the window shows; the key by default.
  • values::Vector{Any}: a menu's or a list's choices; a number's presets.
  • default::Any: the value when none is set; nothing for none.
  • scale::Float64: for a zone property, the factor the window shows its value with (1e-3 shows pascals as kilopascals); the layout keeps the value as given.
  • min::Union{Nothing,Float64}: for an option or a run setting, the smallest number the window accepts.
  • show_if::Dict{String,Vector{Any}}: for a zone property or a run setting, show the field only while each of these options or run settings has one of the listed values. Options are always listed.
  • names::Vector{String}: the names the window shows for values, one per value; none to show the values.

Constructors

Field(key, kind=:numeric; label=key, values=[], default=nothing, scale=1, min=nothing, show_if=Dict(), names=[])

Throws

  • ArgumentError: when kind is not one of the four, or names does not have one name per value.

Examples

julia> f = Field("eta"; label="η [Pa s]", default=1.0e21);

julia> f.kind, f.label
(:numeric, "η [Pa s]")

EasyDraw.subcell_centres — Function
subcell_centres(L, nel, ni) -> Vector{Vector{Float64}}

The centres of the sub-cells of a domain [0, L], with nel cells per axis and ni sub-cells per cell and axis, as one coordinate vector per axis (any dimension): the points points and the window's preview are made of.

The range arithmetic is ElastoPlasm's for its material points (cell size L/nel, the last node last(0:h:L)), so a preview and a simulation built from the same layout have the same points, to the bit.

For a mesher

EasyDraw.Partition — Type
Partition

A layout as disjoint regions, as partition makes it for a finite-element mesher. Neighbouring regions share their edges and vertices.

Fields

  • vertices::Vector{Vector{Float64}}: the [x, z] vertices.
  • edges::Vector{Tuple{Int,Int}}: each edge once, as a pair of vertex indices.
  • left::Vector{Int}, right::Vector{Int}: the region on each side of each edge, left and right of its direction: a zone's index, 0 for the background, -1 outside the domain.
  • side::Vector{String}: for an edge on the domain's boundary, its side ("left", "right", "bottom", "top"); "" inside.
  • regions::Vector{@NamedTuple{zone::Int, outer::Vector{Int}, holes::Vector{Vector{Int}}}}: each part of each zone (or of the background, zone 0): its outer outline, counterclockwise, and its holes, clockwise, as loops of vertex indices.
source
EasyDraw.partition — Function
partition(layout; ngon=32, background=true) -> Partition

The layout as disjoint regions, as a finite-element mesher needs them:

  • each zone where it applies (where zones overlap, the later one wins), clipped to the domain;
  • with background, the rest of the domain as zone 0;
  • shared edges and vertices between neighbouring regions, so that a mesh of them is conforming.

A circle is an inscribed ngon-gon, for itself and for the zones it meets.

Throws

  • ArgumentError: when a zone is a Region or a 3D shape.

Examples

julia> l = Layout(; L=[10, 5], nel=[10, 5], zones=[Zone("base", Block([0, 0], [10, 2]); rho=2700),
                                                   Zone("lens", Ball([5, 2], 1.0); rho=2100)]);

julia> p = partition(l);

julia> sort([r.zone for r in p.regions])
3-element Vector{Int64}:
 0
 1
 2

See also write_geo.

source
EasyDraw.write_geo — Function
write_geo(file, layout; h, ngon=32, background=true) -> file

Write the layout's partition as a Gmsh script, x–z as Gmsh's x–y, making its folder if needed:

  • a Point per vertex, with mesh size h (by default the layout's cell size);
  • a Line per edge, shared by the regions on its two sides;
  • a Plane Surface per region, its outer outline and its holes as Curve Loops;
  • a Physical Surface per zone name, and one called "background";
  • a Physical Curve per side of the domain: "left", "right", "bottom", "top".

Mesh it with gmsh file -2, or with Gmsh.jl.

Examples

write_geo("model.geo", layout; h=0.5)
